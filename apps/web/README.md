# Refleja Tu Interior Web

Bootstrap técnico de la aplicación web para RTI-VS1-003. Contiene únicamente
la base de Next.js, el sistema visual y las pruebas requeridas; no implementa
autenticación, dashboard ni funcionalidad de negocio.

## Comandos

```bash
npm run dev
npm run lint
npm test
npm run build
npm run test:e2e
```

Playwright inicia automáticamente el servidor de desarrollo en el puerto 3100.
